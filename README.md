# 2026 香港單車節 56 公里組 · 資訊預覽

非正式預覽頁，方便對照 56 公里組的關門時間、檢查站位置同路面高度。

**只供參考。不是香港旅遊發展局、香港單車節或任何主辦單位的官方網站。**

賽道、關門時間、交通安排同參加者規定會更新。所有讀者請以官方資料為準：

https://www.discoverhongkong.com/tc/events/cyclothon.html

## 免責聲明

- 路線不是大會 GPX。它是按公開路線圖，沿公路幾何重繪，並把折返畫在去程右方約 30 米，用來表示對面行車線。
- 大會封路當日的行車方向可以同平日單向不同，地圖本身不會標示。
- 檢查站座標是按 FAQ 地名估計，可能偏離實際閘口。
- 點擊路線後，高度圖上的公里是沿這條重繪線的距離，再按 56 公里比例換算，不是車道路中心實測。
- 高度圖是重建，不是實測剖面。橋面用通航淨空一類公開數字（青馬、汀九橋面約 60 米，昂船洲約 76 米）。隧道用路面，不跟山體數值高程。中九龍繞道中段約 −50 mPD，指活動方所講的路面高程，不是建造覆蓋深度（後者曾被報導為離地約 150 米）。折返所以繞道下潛畫了兩次。
- 關門時間表依公開檢查站表整理，包括「不准進入、須掉頭」同「登上大會收容車」。淨時間由起步 05:15 計算。分段下限速度是距離除以該段關門時差，只說明時間有多緊，不是建議配速。
- 使用或轉載本頁資料，風險自負。請勿當作導航、報名或比賽當日的操作依據。

## 頁面怎樣做

單頁 HTML，沒有後端。

1. 檢查站名稱、公里、關門時間同備註，整理自香港單車節公開檢查站表。
2. 公路形狀來自分段路徑拼接：西九龍公路、青衣西北交匯處、青馬大橋、汀九橋、南灣隧道、昂船洲大橋、青沙公路、中九龍繞道，以及博物館道起終點。路網幾何取自 OpenStreetMap，經公開 OSRM 服務沿指定路段取點，再手工補上交匯處缺口。
3. 折返不跟平日單向。回程是去程向右平移約 30 米的平行線，用來表示對面行車線，不是第二條實測軌跡。
4. 地圖用 Leaflet。底圖同中文標註是地政總署 WGS84 XYZ 圖磚。路線畫在圖磚之上；檢查站是獨立標記。
5. 高度圖是按上述路段手繪的折線，不是把 DEM 直接貼上路中心。

## 本機開啟

直接用瀏覽器打開 `index.html`。底圖需要網絡。請不要把全域 `svg { height: auto }` 加回頁面，否則會把 Leaflet 的路線 SVG 高度壓成 0，路線會消失，檢查站標記則仍會顯示。
